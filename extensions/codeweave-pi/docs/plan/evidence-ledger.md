# Nested navigation evidence ledger

## Evidence grades and interpretation

- **Executed:** observed through a bounded disposable fixture or current tool call.
- **Source-verified:** current source directly establishes the behavior; runtime edge cases may remain.
- **Documented:** project or pinned upstream documentation claims the behavior, but this investigation did not execute it.
- **Inferred:** multiple verified facts support the claim, but no owning execution closed it.
- **Open:** the result can change design or implementation order and still needs a discriminator.

Planning claims never become current behavior merely because they appear here.
