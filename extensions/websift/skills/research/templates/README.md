# Research Skill Templates

These package-owned templates are the portable starting point for new W3/W4 investigations under the root selected by [`../references/folder-system.md`](../references/folder-system.md#canonical-location-and-identity). No external template library or maintainer-local path is required. If a user explicitly selected a separate research root with its own templates and `AGENTS.md`, follow that root's conventions instead of overwriting them.

Default files:

- `ACTIVE.md`
- `OBJECTIVE.md`
- `ROUTES.md`
- `FINDINGS.md`
- `EVIDENCE.md`
- `ORIGIN.md` only for imported/moved work
- `OPEN.md` only when open items outgrow `ACTIVE.md`

Older templates in this directory, such as `index.md.template`, `evidence.md.template`, JSONL ledgers, and `w3-mini-ledger.md`, are retained for compatibility and specialized W4/sub-decision use. Do not use them as the default folder structure for new research unless an existing research folder already uses that older format or a task explicitly needs a specialized ledger.
